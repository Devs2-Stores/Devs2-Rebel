# Test Audit (ultra) - Rebel - 2026-10-16

## Verdict

**The suite cannot fail where REVIEW.md says it gates.** Only 4 of the 13 scripts named by REVIEW.md or `r10-final.sh` can exit non-zero on an assertion failure: `journeys`, `r10-tabwalk`, `r10-store-hours`, `settings-usage`. Eight cannot: `r5-axe`, the five lifecycle scripts, `r10-touch-hover` and `preset-contrast`. The one aggregate runner masks even the four that can.

The two CI validators are real gates, but both resolve or skip the exact classes that `AGENTS.md` marks "Critical, blocks completion". I ran read-only scans of the whole tree and found **no live violation today**: the range scan covered 100 JSON files plus all schema defaults, and the locale scan covered 142 Liquid files. So these are latent blind spots, not shipped defects.

Of the five known defects, V-01, V-02 and M-01 are caught by nothing. Q-01 and Q-02 are caught only as FAIL rows in a JSON file (`motion-state.cjs:85,96,101`), and the script exits 0.

Method: the controller's amendments and the candidates' claims were re-read on disk. I ran read-only `node -e` scans, `git ls-files` / `check-ignore` / `status`, and `rg`/`grep` only. No browser, no dev server, no `.env`, no writes. `runs/` is gitignored (`.gitignore:40`, `git ls-files runs` = 0), so the entire e2e suite is untracked. That is stated once here.

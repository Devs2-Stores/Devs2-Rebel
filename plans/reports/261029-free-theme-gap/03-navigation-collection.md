## 4. Rebel equal or better

- Predictive search covers all five resource types (queries, products, collections, articles, pages), with keyboard arrows and Escape (`sections/predictive-search.liquid:13-149`, `assets/search-modal.js:46,353-369`). Horizon's modal shows products and query chips only in the capture.
- Search results page has Products / Articles / Pages tabs with counts, filters, sort and view toggle (`main-search.liquid:91-93`; `rebel-1440-search-page.png`). Horizon's page (`fabric-1440-search-page.png`) is products only.
- Collection pages offer pagination, load more and infinite scroll as a merchant choice (`main-collection.liquid:9,292-312`), plus a sub-collection menu block (`templates/collection.json:26-31`) and a collection-image hero with height/position/title/count (`collection-hero.liquid`).
- Product count reads "Showing 20 / 22 products" (`rebel-1440-collection.png`) against Horizon's "N items".
- Facets: list, swatch, boolean and price range, with active-filter chips and clear all (`collection-facet-filter.liquid:74,207,341`; `collection-active-filters.liquid`).
- Grid/list toggle with list view (`collection-sort.liquid:115-118`), which Horizon lacks.
- Mega menu has keyboard and focus handling (`megamenu.js:78-112`); mobile drawer is a dialog with overlay and close button (`mobile-menu.liquid:3-10`).
- Product card: hover second image, quickview button, sale/new/sold-out badges, contact-for-price text (`product-card.liquid:5,47-69,132-135`; `rebel-1440-search-page.png`).
- List collections has more control than Horizon: collection source or menu, excluded handles, sort, per page, image position/shape (`main-list-collections.liquid:137-480`).
- Footer: mobile accordion with `aria-expanded` (`footer.liquid:114`, `footer.js:16`), newsletter, Follow on Shop, payment icons code, country + language selectors, logo and brand image.
- Header: `<shopify-account>` with merchant-selectable account menu (`header.liquid:32`), cart badge with `data-empty`, sticky toggle that sets `--header-height-sticky` for sticky sidebars (`header.js:16-28`, `theme.css:36`).
- Horizontal overflow: `scrollW` 375 on both themes at 375 (`log2-*.json`).

## 5. Open questions

1. Gap 1: should the card button for multi-variant products open quickview or a lighter "choose options" popover? Quickview exists and is the lowest-effort path; confirm with the owner.
2. Gap 5: is Rebel's first release single-market? If yes, header localization can wait; the footer selector only renders when `available_countries.size > 1`.
3. Gap 4: does the owner want a transparent header on the Rebel hero given scheme-1 text colours on dark photography (contrast would need `anti.qa.visual_quality`)?
4. Footer payment icons rendered 0 in the probe; unclear if the dev store has `enabled_payment_types` empty or the probe selector missed `.footer-payment-icons`. Needs a one-line DOM check.
5. Rebel `/search` and filter flows were captured on the dev server at 1440 only; mobile search results page is not covered here.

### 2.2 Which sections accept theme blocks, static blocks, nesting

- Horizon `@theme` + `@app` + `_divider` on the generic container (`blocks/group.liquid:20-24`, `sections/section.liquid:19-31`) and on 15 more sections (e.g. `main-page.liquid:35-39`, `main-cart.liquid:150-154`, `main-404.liquid:45-49`, `product-list.liquid:97-101`, `footer.liquid:110-114`, `password.liquid:71-75`). Nesting is unbounded in code via `group`; presets reach depth 3 (`section.liquid` presets `faq_section`, `icons_with_text`, `image_compare`).
- Horizon static blocks: 18 sections and 12 blocks call `{% content_for 'block', type:, id: %}` (`product-information.liquid:8,16`, `header.liquid:84-96`, `main-cart.liquid:28-56`, `main-collection.liquid:49,72`, `product-list.liquid:29,39`). Presets mark them `static: true` (55 times in section presets, 7 in block presets). This is how Horizon exposes the product media gallery, card, cart rows, header logo/menu as selectable, styleable blocks. Rebel: 0.
- `closest.*` context inheritance (`closest.product`, `closest.collection`, `closest.article`) lets a plain `text` block resolve dynamic sources inside a card. Rebel: 0 hits for `closest.` in `sections|blocks|snippets|layout|templates`.
- Rebel: `@theme` only in `main-product` (`main-product.liquid:94,155-162`) and `featured-product` (`featured-product.liquid:139,388-395`); `blocks/tabs.liquid:12` renders `content_for 'blocks'` for its `tab` children (the only nesting, 2 levels).
- `enabled_on` / `disabled_on` on blocks: neither theme uses it. Horizon scopes blocks through each container's accepted-type list; Rebel's 21 blocks are accepted by every `@theme` section (so `custom_liquid` or `size_chart` also appear in `featured-product`).
- Block presets: Horizon 70 in 69 block files (almost one each, but pre-populated with child blocks, e.g. `accordion` preset ships 3 rows); Rebel 21, one empty preset per block, no categories (`blocks/badges.liquid:20-24`). Horizon block categories via `t:categories.*` (basic/layout/product/collection/footer/decorative/...); 14 Horizon blocks have none.

## 6. Editor UX
